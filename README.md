
# 📝 Keeper App

A minimal and elegant note-taking web app built with **React** — inspired by Google Keep. Easily add, view, and delete your notes with a clean user interface.

## 🔍 Features

- Create and delete notes
- Live note preview
- Responsive layout
- Styled with Material UI (MUI)

## 🛠️ Technologies Used

- React (Vite)
- JavaScript (ES6+)
- Material UI (MUI)
- HTML5 + CSS3

## 🚀 Getting Started

### 🔧 Clone and Run Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/aftabmadni/Keeper-App.git
   ```

2. **Navigate into the project folder**:
   ```bash
   cd Keeper-App
   ```

3. **Install dependencies**:
   ```bash
   npm install
   ```

4. **Start the development server**:
   ```bash
   npm run dev
   ```

5. Open `http://localhost:5173` in your browser to use the app.
